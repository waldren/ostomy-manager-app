# Requirements

The SRS, PRD versions, and epics/user stories.

- `SRS_v2.md` — current Software Requirements Specification (v2.1). Fully self-contained working spec covering user functionality, non-functional requirements, technical architecture, all epics, and acceptance criteria. Phase 4 (2026-09-04) added urine output tracking, data validation, suggested ranges, preference management, and the administration console, and narrowed v1 scope to colostomy and ileostomy.
- `Ostomy_App_Specification_v1.pdf` — original v1.0 SRS, retained as historical reference only. SRS_v2.md supersedes it and does not require consulting it.
