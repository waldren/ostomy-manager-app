1Ostomy Diary — mobile screen set

Clinical Clarity applied across the set: slate blue for structure and navigation, soft teal for actions and confirmations, crisp off-white ground, Inter throughout with tabular figures for every volume. Cards carry the content; red is reserved for clinical anomalies, so a flagged day is the only saturated thing on screen. Sample data is one patient — day 21 after ileostomy surgery, output running high against low intake. Built against SRS v2.1: colostomy and ileostomy only, urine logged and reported separately from net fluid balance, suggested ranges shown with their source. Touch targets 48px or larger; mL units.
