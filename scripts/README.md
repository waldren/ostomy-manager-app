# Scripts

Development and build tooling scripts.

- `check-no-committed-env.sh` — CI guard; rejects a committed `.env` and scans every `.env.example` against a fixed prefix list (AWS/GitHub/Slack/Stripe-shaped keys, a JWT, a PEM private-key header, credentials embedded in a URL). That is a fast, dependency-free tripwire for those specific shapes — not a general "is this a real credential" scanner, and it will not catch an ordinary password. Run via `pnpm check:env`.
- `dev-reset.sh` — wipes and recreates the shared Docker Compose development stack (`infra/docker-compose.yml`). See `docs/deployment-development.md` "Database lifecycle". Committed with the executable bit set (`chmod +x`, required on the Ubuntu host); also runnable as `pnpm dev:reset` from any checkout, including Windows, where the executable bit doesn't survive a clone.
- `android-emulator.sh` — manages a Pixel 8 AVD for testing `apps/mobile` on-device (`doctor | create | start | wire | up | status | logcat | fingerprint | stop | wipe`). Also exposed as `pnpm --filter @ostomy/mobile emulator:*`. Three things in it are load-bearing rather than incidental: it forwards host ports with **`adb reverse`, never `10.0.2.2`**, because `mock-oidc` advertises an `issuer` derived from the request's Host header and the API validates `iss` against `http://localhost:8090/patient-issuer` — reaching the IdP by any other name yields tokens that are rejected after a sign-in that looked fine; it forwards **only** the api and mock-oidc ports, because a patient device has no business reaching MinIO's console or the admin SPA; and `doctor` reports what is missing without installing anything, since every missing piece is a multi-hundred-megabyte SDK download. `.claude/skills/android-emulator/SKILL.md` carries the judgement around it, including what an emulator run does and does not prove.
